## 🚀 How to Host on GitHub Pages

This project is already pre-configured with relative paths (`base: './'`) in `vite.config.ts`, ensuring that all scripts, styles, and assets resolve correctly under both custom domains and `https://<username>.github.io/<repository-name>/`.

### Option A: Automated GitHub Actions Deployment (Recommended)

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com/new) and create a repository (e.g., `portfolio` or `debaditya-dutta.github.io`).

2. **Push your code**:
   ```bash
   git init
   git add .
   git commit -m "feat: Initial commit of interactive portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Navigate to **Settings** ➔ **Pages** (in the left sidebar).
   - Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
   - The workflow located at `.github/workflows/deploy.yml` will automatically build and publish your site whenever you push to `main`!

---

### Option B: Deploy from `/docs` folder (Instant, Zero-Build)

A pre-built production bundle is already provided in the `docs/` folder!

1. Push the repository to GitHub.
2. In your repository, go to **Settings** ➔ **Pages**.
3. Under **Source**, select **Deploy from a branch**.
4. Set the branch to `main` (or `master`) and select the `/docs` folder from the dropdown.
5. Click **Save**. Your site will be live within 60 seconds!
